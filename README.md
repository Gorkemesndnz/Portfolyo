# 🖥️ Windows XP Temalı Portföy Web Sitesi

Bu proje, modern web teknolojilerini nostaljik bir tasarımla birleştiren, tam fonksiyonel ve etkileşimli bir Windows XP temalı kişisel portföy sitesidir.

![Windows XP Portfolio Preview](https://github.com/Gorkemesndnz/Portfolyom/raw/master/public/bliss.png)

## 🚀 Özellikler

- **Nostaljik Tasarım:** Tamamen Windows XP estetiği ile hazırlanmış butonlar, pencereler ve görev çubuğu.
- **Etkileşimli Masaüstü:** Sürüklenebilir pencereler, ikonlar ve grid tabanlı otomatik yerleşme sistemi.
- **Çoklu Dil Desteği:** Tek bir tıkla Türkçe ve İngilizce dilleri arasında geçiş.
- **Dinamik Veri Yapısı:** Tüm kişisel bilgiler, projeler ve iletişim detayları merkezi bir `data.ts` dosyasından yönetilir.
- **AI Destekli Geliştirme (Vibe Coding):** Proje, yapay zeka araçları ve modern geliştirme metodolojileri ile optimize edilmiştir.
- **Responsive:** Masaüstü ve mobil cihazlarda uyumlu deneyim.

## 🛠️ Teknoloji Yığını

- **React 19** - UI Bileşenleri
- **TypeScript** - Tip Güvenliği
- **Vite** - Hızlı Build ve Geliştirme Ortamı
- **React Draggable** - Pencere ve İkon Sürükleme Mantığı
- **XP.css** - Nostaljik Stil Temeli

## 📦 Kurulum

Projeyi yerel ortamınızda çalıştırmak için:

1. Depoyu klonlayın:
   ```bash
   git clone https://github.com/Gorkemesndnz/Portfolyom.git
   ```
2. Proje dizinine gidin:
   ```bash
   cd Portfolyom
   ```
3. Bağımlılıkları yükleyin:
   ```bash
   npm install
   ```
4. Geliştirme sunucusunu başlatın:
   ```bash
   npm run dev
   ```

## ✍️ Kişiselleştirme

Sitedeki içerikleri değiştirmek için herhangi bir bileşen koduna dokunmanıza gerek yoktur. Sadece `src/data.ts` dosyasını açın ve aşağıdaki bölümleri kendinize göre güncelleyin:

- `about`: Profil resmi, isim ve biyografi.
- `projects`: Proje kategorileri ve detayları.
- `contact`: İletişim bilgileri ve linkler.
- `cv`: CV dosya yolu ve indirme ayarları.
